# Licences of the open-source code in builder/lib

The Maps Builder includes these libraries, each packed into one classic script by `tools/bundle_lib.mjs` without changing the code. Their licences require this text to stay with them.

| File | Library | Version | Licence |
| --- | --- | --- | --- |
| earcut.js | [mapbox/earcut](https://github.com/mapbox/earcut) | 3.2.4 | ISC (not loaded yet: for the 3D view and roofs) |
| flatbush.js | [mourner/flatbush](https://github.com/mourner/flatbush) with [mourner/flatqueue](https://github.com/mourner/flatqueue) | 4.6.2 | ISC |
| polylabel.js | [mapbox/polylabel](https://github.com/mapbox/polylabel) with [mourner/tinyqueue](https://github.com/mourner/tinyqueue) | 2.1.0 | ISC |
| fflate.js | [101arrowz/fflate](https://github.com/101arrowz/fflate) | 0.8.3 | MIT |
| fzstd.js | [101arrowz/fzstd](https://github.com/101arrowz/fzstd) | 0.1.1 | MIT |
| hyparquet.js | [hyparam/hyparquet](https://github.com/hyparam/hyparquet) | 1.31.5 | MIT |
